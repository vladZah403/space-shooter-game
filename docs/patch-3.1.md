# Space Shooter 3.1 — что нового

## Враги
10 новых врагов (`js/foes.js`, спрайты — `art/sheet12_enemies_30.png`). У семи из них есть защита от одного вида оружия: над врагом висит значок с перечёркнутой буквой этого оружия, при первой встрече всплывает подсказка.

| Враг | Волна | Защита / роль |
|---|---|---|
| Вор | 6 | крадёт бонусы и монеты; если сбить — всё вернёт, монеты вдвойне |
| Медик | 9 | лечит соседей |
| Связка | 10 | пара кораблей, луч между ними обжигает и гасит волны Серпа |
| Мортира | 11 | бьёт навесом по красным кругам |
| Зеркало | 12 | отражает лазер обратно в игрока |
| Проектор | 13 | купол гасит плазму у соседей |
| Ледокол | 15 | дробь ×0,2, плазма и ракеты ×1,5 |
| Невидимка | 16 | её не видят молния, ракеты и дроны |
| Гравитон | 17 | разворачивает ракеты, тёмная материя его не берёт |
| Мимик | 19 | 5 с неуязвим к оружию, которым его бьют чаще всего |

Ионный теперь поглощает молнию и роняет двойной энергоблок.

## Боссы
- Три фазы у каждого из 13 боссов. На порогах 2/3 и 1/3 прочности урон упирается в стенку, затем 2,2 с перестройки: босс неуязвим, экран очищается от пуль.
- В каждой фазе свой набор атак и своё движение: преследует, опускается ниже, телепортируется.
- Прочность ×1,7, у первого босса ×1,6. Полоса здоровья разбита на три части, номер фазы показан в HUD.
- «Ярость» на «Кошмаре» и «Боге войны» теперь флаг, а не 4-я фаза: раньше в ней ломались некоторые атаки.

| Сектор | Механика |

| Орбита Земли | спутники с бонусами |
| Пояс астероидов | астероиды-укрытия |
| Туманность Ориона | облака прячут врагов |
| Ледяные луны | разбитый лёд морозит врагов |
| Красный гигант | лавовые астероиды брызжут огнём |
| Изумрудные поля | ядовитые облака |
| Горизонт событий | гравитация гнёт снаряды |
| Сердце галактики | порывы звёздного ветра |
| Кристальный пояс | кристаллы дробят выстрелы |
| Улей | яйца на стенах |
| Пустошь хаоса | порталы для пуль |
| Цитадель | столпы света |
| Трон Оверлорда | Око бьёт лучом, если стоишь на месте |

## Навыки
Новое древо: 4 ветки (Атака, Защита, Техника, Удача), 32 навыка на 5 ярусах.
- Есть ранги; требование «любой из» нескольких навыков.
- Число пассивных ограничено только очками, активных по-прежнему не больше двух.
- 8 активных навыков (`js/skills.js`), у каждого своя анимация запуска: Рельса, Орбитальный удар, Барьер (отражает пули), Замедление, Турель, Чёрная дыра, ЭМИ, Двойник.
- Нова (копия бомбы), Авиаудар, Разгон и Снайпер убраны. Очки за снятые навыки возвращаются сами, вернувшимся игрокам показывается окно «Обновление 3.1».

## Корабль
- Модули забега видны на корабле: у каждого своя деталь (листы `art/sheet14_parts_31.jpg`, `art/sheet15_parts2_31.jpg`).
- Экран «Схема корабля» (из паузы и при выборе модуля): модули разложены по отсекам корабля в разрезе.

## Новый лист реквизита (`art/sheet13_props_31.png`)
- Корабль-лавка в окне Торговца.
- Энергоблоки трёх цветов: обычный, с босса, двойной.
- Событие «Конвой»: грузовики, а в них ящики с добычей.
- Санитарный корабль: если игрок ранен, сбрасывает аптечку.

## Визуал
- На поздних волнах не больше ~16 врагов на экране.
- Цифры урона суммируются раз в 0,35 с.
- Полоски здоровья гаснут через 1,5 с после попадания; зависшие враги расходятся в стороны, а не лежат друг на друге.
- Рельса и лучи врагов — мягкие, со свечением и бегущими импульсами, без резких краёв.
- Серп стал полумесяцем, у молнии появились ветки и ореол.

## Проверки
Боты в headless Chrome:
- длинные забеги на всех сложностях с разными сборками навыков;
- отдельные тесты каждой механики врагов, фаз всех боссов, активных навыков и механик секторов.
